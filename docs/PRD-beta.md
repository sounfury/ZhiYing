## 1. 目标

把工具逐步开放给外部用户，分两个阶段：

1. **宣传期**：在小红书等平台发关系图，访客从官网或帖子里的链接直接打开示例书，不用注册。目的是看有没有人感兴趣，并积累想试用的人
2. **内测期**：分批放号，被邀请的用户上传自己的书。验证两件事：
   - 没读过书的读者愿不愿意用、看不看得懂（核心用户见 PRD §3）
   - 分析结果哪里不准，用户反馈能否沉淀为评测样本

内测期节奏不赶，按反馈和成本慢慢放号。内测不收费、不做积分，成本靠用量上限控制（§4）。

## 2. 优先级

账号与按用户隔离已完成，产品规则已并入 [PRD §5.11–5.12](./PRD.md#511-账号)。其余能力按以下顺序实施，前一项可独立上线：

| 阶段 | 顺序 | 能力 | 理由 |
|------|------|------|------|
| 宣传期 | 1 | PNG 导出（§5） | 宣传配图的来源；本地就能用，不等公网部署 |
| 宣传期 | 2 | 示例书（§3） | 访客从官网或帖子直接打开，不用注册、上传和等待 |
| 内测期 | 3（已完成） | 账号与按用户隔离（PRD §5.11–5.12） | 外部用户上传自己的书之前必须有 |
| 内测期 | 4 | 用量上限（§4.3） | 账号已具备；开放内测前补齐上限，内测期 token 由运营方承担 |
| 内测期 | 5 | 秒传（§4.4） | 大家上传的多半是同几本名著，命中一次省下整本书的分析成本 |
| 内测期 | 6 | 反馈（§6） | 内测能否得出结论取决于它 |
| 内测期 | 7 | TXT 上传（§7） | 扩大可试用的书，放在最后 |

## 3. 示例书

书架预置几本已分析好的书，访客打开网站即可浏览，无需上传和等待。

| 规则 | 说明 |
|------|------|
| 选书 | 公版书，原著与所用版本（译本、校注本）都不能有版权风险；优先选人物多、势力分明的书，如《红楼梦》前 40 回，再配一本中篇 |
| 位置 | 书架上单独一组「示例」，与用户自己的书分开 |
| 链接 | 每本示例书有固定的公开链接，官网和宣传帖可以直接跳转，打开就是关系图；链接可带上人物或章节范围，打开即定位到对应视图（帖子讲哪个人物就跳到哪） |
| 可做 | 浏览关系图、章节聚焦、人物聚焦、筛选、切换布局、查看人名册与证据、导出 |
| 不可做 | 访客和普通用户不能重跑、清空分析、删除；界面不显示这些操作，管理员维护权限见 PRD §5.12 |
| 登录 | 不需要登录，访客可完整使用上面「可做」的全部操作 |
| 上传 | 上传需要登录，账号与隔离规则见 PRD §5.11–5.12 |
| 更新 | 示例书由管理员上传并分析；重新分析期间用户看到的仍是上一版 |
| 用量 | 浏览示例书不占用户额度 |

## 4. 账号、隔离与用量

### 4.1 账号

已完成，产品规则已并入 [PRD §5.11](./PRD.md#511-账号)。

### 4.2 按用户隔离

已完成，产品规则已并入 [PRD §5.12](./PRD.md#512-按用户隔离)。用量上限（§4.3）、秒传（§4.4）与反馈（§6）仍待实现；后续用量额度记录和私有书反馈的归属随书主确定。

### 4.3 用量上限

上限由运营方在配置中调整，界面不提供管理入口。

| 上限 | 作用 |
|------|------|
| 每人书数 | 书架上最多几本（不含示例书） |
| 每人累计分析字数 | 整书分析与单章重跑按实际读取的字数累计，读到一半失败或被取消的章也计入，还没开始读的章不计；秒传不计（§4.4）；删除书或清空分析不退还 |
| 单个文件大小 | 一本书的上传文件上限 |
| 每人同时分析 | 同一时间最多几个分析任务（含单章重跑） |
| 全站每日 token | 当天总消耗达到预算后不再接受新分析，进行中的任务继续完成 |

用户可见行为：

- 书架上显示本人已用 / 总额度（书数、字数）
- 上传或启动分析前，若会超出额度，直接拒绝并说明是哪一项超限、还剩多少；不先开始再中途停止
- 全站预算用尽时提示「今日分析名额已满，请明天再试」；已有结果照常浏览
- 一本书字数超过剩余额度时整本拒绝，不做部分分析；能秒传的书不受字数额度限制
- 管理员不受每人上限约束（要维护示例书和跑评测），但其分析照常计入全站每日 token

### 4.4 秒传

用户上传的文件如果别人（或示例书）已经完整分析过，直接拿到分析结果，不用等，也不花额度。

本节为待实现需求；当前不同用户上传同一文件仍各自分析，行为见 PRD §5.12，后续设计见 DESIGN-beta §2。

| 规则 | 说明 |
|------|------|
| 命中 | 上传的文件与某次分析所用的文件完全相同，且那次分析读完了全书、整书成功，用的是当前版本的分析方法 |
| 不命中 | 只读到第 N 章的结果、失败或取消的分析、正在进行中的分析、分析方法更新前的结果，都不用于秒传；此时照常分析、照常计入额度 |
| 上传 | 文件照常完整上传，由服务器比对；不提供「只发校验值、不传文件」的秒传，避免没有这本书的人凭校验值拿到原文摘录 |
| 效果 | 上传完成即可看图；提示「这本书已有分析结果，已直接加载」，不显示假的分析进度 |
| 额度 | 不计 token 与分析字数，计入书数 |
| 之后的操作 | 秒传得到的书与自己分析的书用法相同，可以重新分析、单章重跑、清空分析、删除，按实际读取的字数计入额度；这些操作只影响自己，其他人看到的结果不变 |
| 重新分析期间 | 与自己的书相同：重新分析完成前看到的仍是原来的结果 |
| 隐私 | 秒传不透露这本书还有谁上传过，也不透露其他用户的任何信息 |
| 重复上传 | 自己书架上已有同一个文件时，不新增一本，直接打开已有的那本 |
| 示例书 | 与示例书相同的文件同样命中 |

## 5. PNG 导出

PNG 有两个用途：宣传期在小红书等平台发的配图直接从示例书导出；内测用户出图、保存到手机、自己看或发出去。两种都要在手机上能看清。

| 规则 | 说明 |
|------|------|
| 内容 | 当前视图下的完整图，不只是屏幕上露出的部分；布局、势力分区、筛选、人物聚焦、章节聚焦如实反映 |
| 附带信息 | 书名、分析范围（全书 / 第 N 章 / 前 N 章）、图例（硬 / 中 / 软线型与势力颜色）、ZhiYing 水印 |
| 清晰度 | 在手机上双指放大后人名仍可辨认；人多的图不能因为整体缩小而糊成一片 |
| 文字 | 导出图里显示人名与主要关系文字，不依赖悬停才能看到 |
| 适用 | 示例书和自己的书都可导出；导出不占额度 |

## 6. 反馈

用户不改图，只报告问题。这与 PRD §5.8「不做人工纠错」一致：反馈不会改变分析结果，只供开发者改进和补充评测。

| 规则 | 说明 |
|------|------|
| 入口 | 人物详情、关系详情、势力块上各有「这里不对」；另有一个面向整个产品的通用反馈入口。需要登录，访客点击时提示登录 |
| 填写 | 点击即可提交；可选一个问题类别（如人物重复、关系错误、势力不对、缺了人或关系、其他），可选补一句说明 |
| 自动附带 | 书、对象（人物 / 关系 / 势力）、当前分析范围、结果版本、提交时间 |
| 用户可见 | 提交后提示「已收到」；同一对象可以再次提交 |
| 管理员可见 | 按书查看反馈列表，能导出供评测集使用；示例书的反馈能跳转到对应的人物或关系。私有书只看反馈内容与提交时的对象名称，不能打开那本书（PRD §5.12） |
| 示例书 | 同样可反馈；示例书的反馈价值最高，因为管理员可以直接核对 |

## 7. TXT 上传

网文读者手里大多是 TXT。

| 规则 | 说明 |
|------|------|
| 编码 | 自动识别常见中文编码（UTF-8、GBK 等），不要求用户转码 |
| 切章 | 内置多种常见的分章方案（「第 X 章 / 回 / 节」、卷 + 章、数字序号、英文 Chapter 等，以及按长度分段），上传时自动选一种；都不适用时按长度分段，并告知用户这本书是按长度分的 |
| 换方案 | 书详情显示当前分章方案；用户可以改选其他方案，改选前能预览每种方案切出的章数与开头、中间、结尾几章的标题。已有分析结果时，改选会清空分析（先确认，已用额度不退还） |
| 秒传 | 同一个 TXT 文件且分章方案相同才命中（§4.4） |
| 书名 | 取文件名，去掉扩展名 |
| 结果 | 切章后与 EPUB 走同一套分析、出图、导出流程 |
| 不做 | 手动调整章节边界；用户自己写分章正则 |

## 8. 内测不做

- 支付、积分、付费档位
- 人工纠错（PRD §5.8）
- 严格防剧透、头像框模式、SVG / Mermaid 导出
- 手机号或邮箱注册、自助找回密码
- 只发校验值、不上传文件的秒传（§4.4）

## 9. 开放问题

| 问题 | 备注 |
|------|------|
| 示例书具体选哪几本、用哪个版本 | 需确认版本无版权风险 |
| 各项上限的初始值 | 等单本书成本测准后确定（读章缓存命中率、秒传命中率会显著影响） |
| 不同来源的同一本书 | 秒传第一版只认同一个文件；同一本书换了封面、元数据的文件不命中。之后按章节正文复用，可让这类文件也省下大部分成本（DESIGN-beta §2.5） |
| 官网 | 页面内容与形式未定；本文只要求示例书能从官网跳转（§3） |
| 公网部署与合规 | 宣传期就要公网部署示例书；服务器地区、域名备案、生成式 AI 服务的合规要求；用户协议与隐私说明 |
| 手机端浏览 | 手机打开网页的体验尚未验证，是否纳入内测待定 |
